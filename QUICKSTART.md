# Quick Start Guide

## Installation (5 minutes)

1. **Install Python 3.8+** (if not already installed)
   - Download from: https://www.python.org/downloads/
   - During installation, check "Add Python to PATH"

2. **Open Terminal/Command Prompt** in project folder

3. **Create Virtual Environment**:
   ```bash
   python -m venv venv
   ```

4. **Activate Virtual Environment**:
   ```bash
   # Windows
   venv\Scripts\activate
   
   # Linux/macOS
   source venv/bin/activate
   ```

5. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
   *This will take 5-10 minutes*

## Running the Application

1. **Start Server**:
   ```bash
   python app.py
   ```

2. **Open Browser**:
   - Go to: http://localhost:5000

3. **Allow Camera Access** when prompted

4. **Start Interview**:
   - Click "▶ Start Interview"
   - Interview yourself for 1-2 minutes
   - Click "⏹ Stop Interview"
   - View your performance report

## Tips for Best Results

✅ **DO**:
- Good lighting on your face
- Look at the camera (not screen)
- Stay 2-3 feet from camera
- Use natural gestures

❌ **DON'T**:
- Sit in darkness
- Look away constantly
- Move out of frame
- Fidget excessively

## Quick Troubleshooting

**Camera not working?**
- Check browser permissions
- Restart browser
- Try different browser

**Slow performance?**
- Close other programs
- Check CPU usage
- Ensure good internet

**Face not detected?**
- Improve lighting
- Face camera directly
- Remove obstructions
